# Китайский Original — тестовая версия

Тренажёр к учебнику 发展汉语 (Developing Chinese, 2nd ed.), 初级综合 I, уроки 1–10, со словами из книг 初级听力 I, 初级读写 I, 初级口语 I.
Весь тренажёр — один файл `index.html`, без сервера и без регистрации; прогресс хранится в браузере на устройстве.
Кнопка EN на главном экране — английская версия.

Порядок черт — Make Me a Hanzi / hanzi-writer-data (Arphic Public License); письмо иероглифов — Hanzi Writer (MIT).

Клубы: тот же тренажёр по адресу клуба показывает логотип и подпись этого клуба только его ученикам.
- `/` — без клуба;
- `/idea/` — клуб «Идея» (логотип «Идея!», значок на телефоне «Идея! 中文»). Надпись логотипа набрана шрифтом Bad Script (SIL Open Font License 1.1) и переведена в кривые.
